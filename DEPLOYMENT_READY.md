## 🐛 If Something Goes Wrong

### Check These:
1. **Render Logs** - Dashboard → Your Service → Logs
2. **Aiven Status** - Make sure database is running
3. **Environment Variables** - Verify all are set correctly
4. **GitHub** - Make sure code pushed successfully

### Common Issues:
- **Build failed**: Check package.json
- **Database error**: Verify Aiven credentials
- **Site not loading**: Wait 60 seconds (might be waking)
- **Login issues**: Check SESSION_SECRET is set
